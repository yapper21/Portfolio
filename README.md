# Yazish Safa & Uneeb Zia - Software Engineering Portfolio

Production interactive software engineering portfolio for **Yazish Safa & Uneeb Zia**.

## 🛠️ Built With
- **Frontend**: React 19, Vite, Tailwind CSS, Lucide Icons
- **Style & Design**: Sky Blue & White Palette, Times New Roman Typography
- **Deployment**: Vercel

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
